# Demo Video Script (2-3 minutes, Clipchamp or Teams recording)

Use test data only. Blur or avoid tenant URLs and real emails.

| Time | Show | Say |
|---|---|---|
| 0:00-0:20 | Process map (before vs after) | "Manually, each registration took 12 steps. This automation removes 11 of them." |
| 0:20-0:45 | SharePoint site: Sessions and Registrations lists | "Sessions holds capacity and seats taken; Registrations holds each person and status." |
| 0:45-1:30 | Submit the Form for a session with seats left; then show new Registrations row, SeatsTaken +1, Outlook invite, Teams post | "Flow A checks capacity, confirms, updates seats, sends the invite and posts in Teams." |
| 1:30-1:50 | Submit again for a full session | "When full, the person is waitlisted and emailed automatically." |
| 1:50-2:15 | Change a status to Attended, then No-show; show emails | "Flow C sends feedback or a follow-up with the next session and notifies the manager." |
| 2:15-2:40 | Flow run history + failure email example | "Each flow has Try/Catch error handling that alerts the training lead." |
| 2:40-3:00 | SOP page | "The SOP covers owners, adding sessions, fixing runs, permissions and data retention." |
